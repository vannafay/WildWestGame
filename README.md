**# 🤠 Wild West Adventure

A Java-based, interactive adventure game inspired by **The Lone Ranger**. Travel through a Wild West storyline, make decisions, collect items, and see where your choices take you!

This game was created as my final project for an Honors Anti-Hero Seminar in Fall 2024. It was my first experience developing a complete video game, combining storytelling, decision-making, and Java programming.

## 🎮 About the Game

Step into the Wild West and experience an adventure where your decisions matter. As you progress through the story, you'll encounter different scenarios that challenge you to make choices. Some decisions will help you along the way, while others may cost you valuable lives.

Your goal is to make it through the adventure while managing your inventory and keeping your character alive!

## ✨ Features

- **Interactive Storytelling:** Experience a point-and-click adventure inspired by The Lone Ranger.
- **Decision-Based Gameplay:** Make choices that influence your journey and outcomes.
- **Inventory System:** Collect and manage items throughout the game.
- **Life System:** Keep track of your remaining lives as you navigate challenges.
- **Game Over Mechanics:** Be careful! Making the wrong decisions can cost you lives. Lose all your lives, and the game ends.
- **Graphical User Interface:** Navigate the adventure through an interactive game interface.

## 🚀 Getting Started

### Requirements
- Java Development Kit (JDK)
- Eclipse IDE (recommended)

### Running the Game

1. Clone the repository:

   ```bash
   git clone https://github.com/vannafay/WildWestGame.git
   ```

2. Open Eclipse.
3. Import the downloaded project using **File → Import → Existing Projects into Workspace**.
4. Locate the main Java class containing the `main()` method.
5. Right-click the file and select **Run As → Java Application**.

## 📂 Project Structure

The project is organized into Java source files and supporting resources, including:

- `src/` – Java source code
- `Main/` – Core game functionality and management
- `Event/` – Game event handling
- `pics/` – Game images and visual assets
